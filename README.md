# 知音 · 视频 / 音频 / 文字稿提取器 v0.5

## 此版本重点：删除网页打开流程
- 删除了「打开网页」按钮、解析失败时跳转外部网页的行为、以及网页无法打开的失败页面。
- 一次点击只运行一个解析任务。解析锁阻止多次点击同时请求，最多请求原分享页和一个备用公开作品页。
- 失败时原地展示原因（如 403、404、超时、平台访问限制），并提供“手动重试”“导入视频”“复制错误”。
- 优化解析时延，避免长时间在 3/3 步骤循环。
- 视频 MP4、音频 M4A、本地媒体导入、SenseVoice 中文完全离线转写和 TXT / SRT 导出全部保留。
- 因登录验证、权限、平台限制等原因依然可能无法解析部分链接，不绕过认证。

## 安装与使用
在 GitHub Actions 中下载 \`douyin-export-no-web-v05-apk\`，解压取得 \`app-debug.apk\`。
建议先导出重要文字稿，调试签名不同可能需要卸载旧版后安装新版本。

## 依赖
Java 17 / Kotlin 2.0.21 / Android Gradle Plugin 8.7.3 / Gradle 8.9，内置 SenseVoice Small INT8 与 sherpa-onnx。
APK 在 GitHub Actions 构建时下载模型和本地推理组件，安装后无需语音识别 API。实际视频解析需联网并受平台访问策略限制。
