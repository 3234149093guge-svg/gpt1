# 知音 · 视频/音频/文字稿提取器 v0.6

## v0.6 修复 v0.5 的解析回退
用户反馈：某视频在 v0.4 能下载，而 v0.5 对作品 7706005272531330939 显示 “未能获取可下载的视频地址”。
检查代码发现 v0.5 从 v0.4 的 **两个备用公开分享页面** 削减成了一个，同时把最大 HTML 体积和网络超时设置缩小。v0.6 恢复双来源解析并适度放宽连接超时。

- 按顺序检查原分享链接、iesdouyin 移动公开分享页、douyin 公开分享页；每个地址至多请求一次，不会循环重新尝试。
- 保留 v0.5 的简洁交互，不添加“打开网页”按钮，也不会弹出或跳转至抖音网页。
- 失败时在当前界面显示各阶段的技术诊断，不会把“未得到播放地址”直接断定为视频删除。
- 修复解析逻辑后，MP4 视频下载、M4A 音轨、SenseVoice 离线中文转写 TXT/SRT 全部保留。
- 解析链接仍需网络，公开分享地址能否返回媒体 URL 取决于抖音网页响应。

## 重要：验证状态
CI 只验证源码能否成功编译并包含模型。**该作品能否重新解析成功仍需在手机上实测。**
如果实测仍失败，请在 App 内点“复制错误”发送完整诊断内容，以确认是哪个公开来源返回无播放地址或网络错误。
